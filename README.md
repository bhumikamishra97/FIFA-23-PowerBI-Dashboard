# FIFA 23 Power BI Dashboard

## Project Overview
This project analyzes FIFA 23 player data using Power BI Desktop and DAX. It explores player performance, potential, nationality, market value, and wages.

## Dataset
- 17,660 FIFA 23 player records
- Player ratings, age, nationality, club, market value, and wages

## Tools Used
- Power BI Desktop
- DAX
- CSV Dataset

## Dashboard Pages
1. Overview
2. Performance
3. Financial Analysis

## Project Files
- `FifaAnalysis (1).pbix` – Power BI dashboard
- `CLEAN_FIFA23_official_data (1).csv` – Dataset
- `FifaPowerBIProject.pdf` – Project documentation

## Key Learning
Practiced data analysis, DAX measures, data categorization, and dashboard visualization.

FIFA 23 Player Data Analysis using Power BI and DAX. Interactive dashboards for player performance, potential, market value, wages, and nationality analysis using 17,660 player records.
